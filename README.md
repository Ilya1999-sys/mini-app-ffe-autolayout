# Figa Trainer Quiz App (MVP)

Статический Telegram mini-app с дизайном, собранным из HTML/CSS-блоков (не скриншотных экранов):

- welcome экран -> 7 вопросов;
- 2 варианта ответа на каждый вопрос;
- выделение выбранного варианта цветом `#C9F938`;
- кнопка `Ответ` заблокирована до выбора;
- экран `Верно` / `Не совсем правильно` после каждого ответа;
- итоговый экран с количеством баллов;
- кнопка `Получить выгоду` отправляет результат в бот через `Telegram.WebApp.sendData`;
- персонаж подключен отдельными PNG `x2` из Figma (`assets/characters/*`).

## Быстрый локальный запуск

Из папки проекта:

```bash
python3 -m http.server 4173
```

Открыть в браузере:

`http://localhost:4173`

## Как подключить к Telegram-боту

1. Создать бота через `@BotFather`.
2. Задеплоить эту папку на Vercel/Netlify (нужен `https`).
3. В `@BotFather` -> `/mybots` -> Bot Settings -> Menu Button:
   - Type: `Web App`
   - URL: адрес вашего деплоя.
4. Добавить в боте кнопку `Открыть тест`, которая ведет в mini-app.
5. В серверной части бота обработать `web_app_data` и разобрать JSON.

## Формат payload, который отправляет кнопка «Получить выгоду»

```json
{
  "type": "quiz_completed",
  "score": 5,
  "total": 7,
  "offerOptions": [
    "Курс Figma для UX-редакторов",
    "Базовый курс Figma для редакторов",
    "Курс Figma для презентаций",
    "Разовая консультация",
    "Пакет из 3 консультаций",
    "Пакет из 5 консультаций"
  ],
  "answers": [
    {
      "question": 1,
      "selected": 1,
      "correct": 1,
      "isCorrect": true
    }
  ],
  "requestedAt": "2026-09-22T00:00:00.000Z"
}
```
